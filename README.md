# Landing page de nutrição — demonstração

Página estática responsiva, com CSS, JavaScript e imagens incorporados em `index.html`.

**Demonstração fictícia:** nome da clínica, personagem, textos de atendimento e imagens são ilustrativos. O botão de WhatsApp encaminha ao formulário enquanto o telefone real não é configurado; o formulário não envia nem armazena dados sem um endpoint. Substitua os dados demonstrativos antes de usar comercialmente.
